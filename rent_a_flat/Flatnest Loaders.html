Flatnest · animated svg

Loaders that feel like home

Six self-contained SVG loaders in the Flatnest palette. No libraries, no JSON, no fonts. Drop into web, React, React Native (in a WebView) or Android/iOS as a raw asset.

How to use

Each loader is a single .svg file with embedded SMIL animation — works without any runtime.

HTML<!-- as an image --> <img src="loaders/pin-bounce.svg" width="96" alt="Loading"/>
Reactimport Loader from './loaders/pin-bounce.svg'; <img src={Loader} width={96} alt="Loading" />
React Native// requires react-native-svg-transformer import Loader from './loaders/pin-bounce.svg'; <Loader width={96} height={96} />
Inline (full control)// Paste the <svg> markup // directly into JSX/HTML. // SMIL animations play // automatically.
